Test 1: Ett ledigt rum visas och ett upptaget rum filtreras bort

Sökning: Hotell i Båstad, den 11–12 december för 2 personer.



select r.id, a.name, r.rooms_number, r.capacity, r.price_per_night
from Rooms r
join Accomodations a on a.id = r.accomodation_id
join Cities c on c.id = a.city_id
where c.name = 'Båstad'
and r.capacity >= 2
  and r.id not in (select room_id from Bookings
                   where booking_start < '2026-12-12'
                     and booking_end > '2026-12-11');


Resultat

Ledigt rum: rooms.id 3 (Skansen 201) har inga bokningar då och visas.
Upptaget rum: rooms.id 2 (Skansen 102) är bokat 10–13 december och visas inte.

För att se deras bokningar

select id, room_id, booking_start, booking_end
from Bookings
where room_id in (2, 3);

Test 5: Kombinerade sökfilter och båda sorteringsalternativen fungerar 

5a. Sortera lediga rum i Båstad med kapacitet för minst 2 personer

SELECT r.id, a.name, r.price_per_night, a.rating, a.pool, a.restaurant
FROM Rooms AS r
INNER JOIN Accomodations AS a ON r.accomodation_id = a.id
INNER JOIN Cities AS c ON a.city_id = c.id
WHERE c.name = 'Båstad'
  AND r.capacity >= 2
  AND r.id NOT IN (
      SELECT room_id
      FROM Bookings
      WHERE booking_start < '2026-12-17'
        AND booking_end > '2026-12-16'
  )
  AND a.pool = 1
  AND a.restaurant = 1
ORDER BY r.price_per_night

5c. Sortera efter rating (högst först)


SELECT r.id, a.name, r.price_per_night, a.rating, a.pool, a.restaurant

INNER JOIN Accomodations AS a ON r.accomodation_id = a.id
INNER JOIN Cities AS c ON a.city_id = c.id
WHERE c.name = 'Båstad'

      SELECT room_id
      FROM Bookings
      WHERE booking_start < '2026-12-17'
